# StudyNudge · 学习任务提示器

置顶小窗 + 定时提醒 + 日期联动的任务清单，为「图形学 / 考研」双线学习设计。
界面用 Python 标准库（tkinter）；托盘图标用 `pystray` + `Pillow`（已装，缺了会自动退回贴边条）。

---

## 1. 启动

| 方式 | 操作 |
|---|---|
| 手动 | 双击 `启动 StudyNudge.bat` |
| 命令行 | `C:\software\Python311\pythonw.exe E:\Code\04_Tools\StudyNudge\main.py` |
| 开机自启 | 已在启动文件夹创建 `StudyNudge.lnk`；开关在「设置 → 开机自启动」 |

**关闭 = 收到系统托盘**：点窗口右上角 ✕ 只把窗口藏起来，任务栏右下角（可能要先点 `^` 展开隐藏图标）会有一个圆环图标，不退出进程。

- 双击托盘图标 / 右键 →「展开窗口」：恢复小窗
- 右键托盘图标：今日总览 / 本周俯瞰 / 暂停提醒 1 小时 / 开机自启 / 退出
- 图标本身也是进度条：蓝 = 待办中，绿 = 今日已清空，红 = 有逾期
- 真正退出：右键托盘图标 →「退出 StudyNudge」，或「设置 → 退出程序」
- 不想要托盘：「设置」里取消「点 × 收到系统托盘」，收起时退回右上角贴边条

重复双击启动不会开第二个窗口，只会把已有窗口提到前面。

## 2. 界面

```
┌──────────────────────────────────────┐
│ 10月27日 周二 · W7            逾期 1 │  ← 日期 / 周次 / 逾期角标
│ 完成 0/6 · 剩余约 7.5h · M3 RTIOW…   │  ← 完成度 / 剩余预估 / 当前模块
├──────────────────────────────────────┤
│ ☐ 论文轻轨：RTiOW 第 3 章笔记  → ▶ ✎ │  ← 点 ☐ 完成；→ 延期；▶ 计时；✎ 编辑
│   ● 其他 · 1h · 逾期 2 天            │
│ ☐ 数学：中值定理 + 导数应用    → ▶ ✎ │
│   ● 数学 · 2h · 每日                 │
├──────────────────────────────────────┤
│ ＋新增   明日   本周   统计   设置   收起   │
└──────────────────────────────────────┘
```

- **☐ 勾选**：一次性任务标完成；每日/每周任务只记「今天已完成」，明天照常出现。
- **→**：延期到后一天（仅一次性任务），延期 3 次会红字提醒你拆分或砍掉。
- **▶**：计时器，再点 ■ 停止，实际小时数累计进任务（统计页可见）。
- **✎**：编辑 / 删除任务。
- **明日 / 今日**：按钮文字跟着视图变。看的是今天 → 写「明日」；切到明天后 → 写「今日」，再点一下就回到今天。在明日清单里勾选 = 提前完成，记到明天，明天不会再提示。
- **本周**：一周俯瞰（见第 5 节）。
- **收起**：藏到系统托盘（没有托盘时退回右上角贴边条）。

## 3. 提醒规则

- 每 **30 分钟**（设置里可改）检查一次，有未完成项才提醒：窗口展开置顶 + 顶部红色横幅 + 边框闪烁 + 系统提示音。
- **有逾期任务时**横幅不自动消失，必须点一下；只有普通待办时 60 秒后自动收起。
- **免打扰** 默认 23:30–07:00，期间不提醒。
- **全屏勿扰**（默认开）：前台窗口盖满整块屏时（游戏、F11 视频、全屏播放器）不弹提醒、不抢焦点、不响提示音，只在 `data\studynudge.log` 记一行；退出全屏后下一次检查（≤ 1 分钟）立刻补提醒。最大化的普通窗口不算全屏（不会误判），设置里可关。
- 右键贴边条 →「暂停提醒 1 小时」。
- 当天全部勾完 → 不提醒，标题栏显示「✓ 已清空」。
- 开机首次启动弹出「今日总览」：几项未完成、几项逾期、本周累计 vs 28h 目标。

## 4. 任务类型

| 类型 | 含义 | 逾期判定 |
|---|---|---|
| 一次性 | 某天要做的具体事（作业、笔记、论文） | 过了执行日还没勾 → 显示逾期 N 天 |
| 每日 | 每天都要做（数学、图形学、英语单词） | 不判逾期 |
| 每周 | 指定星期（阅读 三/六、笔记与复盘 周日、论文 周六） | 不判逾期 |

**任务从哪来：进度.md（唯一真源，v3 起）**

提示器不再写死任务，而是启动时、跨零点时、以及发现 进度.md 被改过时（每分钟看一次文件时间戳，约 1 分钟内自动生效）重新解析下面这一小节：

```markdown
## 0.5 当前执行（StudyNudge 读取；改这一节 = 改提示器任务）

- [math] 数学 · 0 基础课 第 14 讲 | 1.5 | 下一讲第 15 讲
- [graphics] 图形学 · L15–L16 看课 | 0.9 | 看完接作业 7
- [english] 英语 · 背单词 20 分钟 | 0.3 | 5500 词
- [reading] 阅读 · 教材/长文 1 小时 | 1.0 | 周三、周六 | 每周 3,6
```

格式：`- [学科(#子项)] 标题 | 小时 | 备注 | 排期`

- 学科：math / graphics / english / reading / other，也可直接写中文
- **课次自动推进**：备注里写 `每天 4 讲`（或 `每日 +4`），勾完这条 → **次日**标题里的课次自动 +4 并回写本文件（`17–20` → `21–24`，`L15–L16` → `L17–L18`）；当天勾完仍显示原那一条，不会变成新的未完成
- **取消就回退**：推进后撤销完成（哪怕已经过了好几天），标题会退回上一档并写回 进度.md，不会卡在下一阶段
- **截止日期**：备注里写 `共 46 讲 · 截止 11-04`（或 `11/04 前`），本周俯瞰会标「本段截止 周X（今天）」「全课程 46 讲 · 11-04 截止（剩 7 天）」，主窗副行也会显示 `截止 11-04`
- **从哪天开始**：排期写 `从 10-29`，这条从那天起才出现（前置没做完的任务用这个）
- **作业类任务**：用 `一次 2026-10-29`——从那天起出现，没做完会天天带逾期天数提醒，勾掉就消失
- 排期：不写 = 每天；`每周 3,6` = 周三、周六；`一次 2026-11-02` = 一次性
- 同一学科可写多条，用 `#子项` 区分（如 `graphics#demo`）
- **标题变了 = 换了个东西要做**：清掉今天那条的完成标记，重新回到待办
- 没写进这一节的任务不会出现；删掉一行 = 删掉任务
- 从这一节消失、但打过卡的任务留档（周统计仍算得到），不再显示

退化规则：找不到「当前执行」小节时，读「查缺补漏（待补清单）」里未勾选的 `- [ ]` 条目，按每天提醒生成任务。

同步状态：标题行右侧 `↻ 今天`，点一下立即重同步（或 设置 → 进度文件 → `↻ 同步`）；进度.md 自称的「最近更新」超过 5 天会弹一次提醒，超过 7 天状态变红。

**任务三种节奏（主窗框色不同）**

| 类型 | 怎么判 | 框色 | 例子 |
|---|---|---|---|
| 每日任务 | 没写步进的每日任务 | 灰框 | 背单词、SeasonDrive |
| 推进任务 | 备注写了 `每天 4 讲` | 蓝框 | 0 基础课 17–20 讲 |
| 周进度任务 | `每周 3,6` | 绿框 | 阅读教材（周三）、论文（周六） |

左侧 4px 色条始终是学科色（数学红 / 图形学蓝 / 英语绿 / 阅读黄 / 其他灰）。

**延期（手动）**：每行右侧 `↷` = 延到明天。延期的任务当天从列表消失，**次日出现在列表最上面**：橙底 + 红框 + 「延期」标签 + 已延次数，其他任务照旧排在后面，不会被挤掉。延到第 3 次会提醒你拆分或砍掉。

**提前做（学有余力）**：今天全部勾完后，列表底部会出现「明日 · 可提前做 N 项」，明天的任务直接列出来（推进型显示的是**下一条课次**，如 21–24 讲）；在这里勾掉就算明天完成，明天列表就少一项，后面的任务自然往前挪。

**旧版内置清单（v2；v3 起由 进度.md 覆盖，仅作对照）**

| 任务 | 学科线 | 频次 | 预估 |
|---|---|---|---|
| 数学 · 基础篇（武忠祥）例题 | 数学 | 每日 | 1.0h |
| 数学 · 严选题 / 错题回顾 | 数学 | 每日 | 0.7h |
| 图形学 · 看课 / 读书 | 图形学 | 每日 | 0.8h |
| 图形学 · 动手实现 / 作业 | 图形学 | 每日 | 0.9h |
| 英语 · 背单词 20 分钟 | 英语 | 每日 | 0.3h |
| 阅读 · 教材 / 长文 1 小时 | 阅读 | 每周 三、六 | 1.0h |
| 论文轻轨 · 隔周 1 篇 | 阅读 | 每周 六 | 0.5h |
| 技术笔记（双周 1 篇） | 其他 | 每周 日 | 0.5h |
| 周复盘 30 分钟 | 其他 | 每周 日 | 0.5h |

合起来约 29h/周，对得上 26 周模板。这套静态清单从 v3 起被 进度.md 的「当前执行」小节取代：首次同步时没打过卡的直接删除，打过卡的留档（周统计仍算得到）。

日期与周次联动：**W1 = 2026-09-14**，按 26 周规划自动算当前周次和模块（M1–M6）。

## 5. 本周俯瞰

点底栏「本周」（或点标题里的 `W7`）打开；**窗口可拉伸**，任务名最多显示 34 字，拉宽就看得全：

表格按类型分三组，推进型额外标出本周能推到哪（`本周剩 5 天 × 4 → 到 33–36 讲`）：

- **每日任务** —— 每天都要做（背单词、SeasonDrive）
- **推进任务（按课次往前走）** —— 看课、教材章节这类有进度的
- **周进度任务（每周固定几次）** —— 阅读、论文、笔记、复盘

```
任务                    一  二  三  四  五  六  日
                        26  27  28  29  30  31   1
数学 · 基础篇（武忠祥）例题  ·  ✓   ○   ○   ○   ○   ○
数学 · 严选题 / 错题回顾    ·  ✗   ○   ○   ○   ○   ○
英语 · 背单词 20 分钟      ·  ○   ○   ○   ○   ○   ○
阅读 · 教材 / 长文 1 小时   ·  ·   ○   ·   ·   ○   ·
周复盘 30 分钟            ·  ·   ·   ·   ·   ·   ○
```

- ✓ 已完成（绿） / ✗ 漏了（红） / ○ 待做（今天那列高亮）/ · 这天不用做
- **点格子可以补勾**：前几天忘了勾的，直接点一下就记上；点错了再点一下取消。未来格子不能点。
- 顶部一行是本周完成率 + 各学科线 已完成 h / 目标 h。
- 底部「导出本周 CSV」把这张表存成 `data\exports\W7_2026-10-26.csv`。

## 8. 文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 入口：高 DPI、单实例、异常日志、`--selftest` 自检 |

## 9. 已知限制

- 托盘图标是第三方库 `pystray`（已装）。如果哪天 Python 环境重装没了，程序会自动退回右上角贴边条，不会崩。
- **Win11 默认把新托盘图标藏在 `^` 溢出区**：没看到图标就点任务栏的 `^`，把 StudyNudge 拖到任务栏上，以后就一直显示。
- 不会自动识别「全屏游戏/视频」并静默，需要的话手动「暂停提醒 1 小时」。
- 提醒靠 tkinter 的定时器，电脑睡眠期间不计时；唤醒后最多 1 秒内补上。
- 一次只能有一个实例；自启动项与手动启动共用同一个实例。

## 打包成 exe（v1.0）

```powershell
cd E:\Code\04_Tools\StudyNudge
python -m PyInstaller --noconfirm --clean --windowed --onedir --name StudyNudge `
  --icon assets\icon.ico --add-data "assets;assets" `
  --hidden-import pystray._win32 --hidden-import PIL._tkinter_finder main.py
```

产物：`dist\StudyNudge\`（约 69 MB），里面 `StudyNudge.exe` + `_internal\`。
再补三个文件后压成 zip 即可分发：

- `使用说明.md`
- `data\任务列表.md`（由 `progress.TEMPLATE` 生成，用户直接编辑这个文件）
- `README_开发说明.md`（可选）

打包后的路径规则（`paths.py`）：数据目录 = exe 所在文件夹的 `data\`；只读资源（assets/icon.ico）= `_internal\`。
`--selftest` 在 exe 里也能跑，输出写到 `data\selftest.log`（窗口模式没有 stdout）。

## 主题与背景

- 主题色：`theme.PRESETS` 里的 7 个预设 + 系统色饼自定义；界面色由 `theme.palette()` 从主题色派生（BG/BG2/BG3/ACCENT）。
- 背景照片：`theme.compose_bg()` 把照片按 alpha 与「主题色→底色」的纵向渐变混合；照片同时铺在主窗底层和列表滚动区（行间空隙/空白处可见），界面配色按 alpha 向照片主色偏移。
- 图标：`tools\make_icon.py` 用 Pillow 画原创 Q 版头像，输出 `assets\icon.ico`（16–256 多尺寸）。
